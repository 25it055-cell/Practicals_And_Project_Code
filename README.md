## 🏛️ MiniBank Project — Object-Oriented Banking Application

Located in the [`Minibank/`](./Minibank/) directory:
- **Architecture:** Layered architecture (`model`, `service`, `repository`, `interfaces`, `exception`, `util`, `test`)
- **Key Features:** Account creation, deposit, withdraw, inter-account transfers with deadlock prevention, serialization, regex validation, reflection-based annotation verification, multithreading transaction processing, NIO daily reports.
- **Build Scripts:** `build.bat`, `run.bat`, `test.bat`, and `manifest.txt`.

### How to Build & Run MiniBank:
Navigate into `Minibank/`:
```cmd
cd Minibank
build.bat
run.bat
```
To execute automated verification tests:
```cmd
test.bat
```
